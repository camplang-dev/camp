# Camp Language Guide

The language guide is for readers who want to learn Camp as a language for
writing native code. It starts with small complete programs, then builds toward
the API shapes that matter in real Camp projects: declarations, everyday
types, lifetimes, allocation, errors, interfaces, generics, iterators, async
code, native interop, and metadata.

Read it straight through the first time, then use the sidebar as a return path
when you need to revisit a specific part of the language.
