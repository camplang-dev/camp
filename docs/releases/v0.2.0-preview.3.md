Camp v0.2.0-preview.3 fixes a string-to-span lowering bug and improves the
editor setup experience across the bundled editor integrations.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Fixes

- Fixed lowering from `string` to `const char[]` so a string-returning function
  is evaluated once. The generated code now materializes the string value before
  deriving both the element pointer and length.
- Fixed the VS Code PowerShell installer so it correctly invokes the selected
  `code` command when installing the bundled extension.
- Fixed VS Code installer setup so development installs point the extension at
  the intended Camp language server.
- Fixed micro syntax highlighting for regular-expression compatibility.
- Fixed the micro installer so it can update an empty settings file.

## Editor Tooling

- Added Fresh editor support, including syntax highlighting, package metadata,
  setup scripts, and language-server configuration.
- Updated bundled editor syntax files for interpolated strings.
- Release archives now include Fresh setup scripts alongside the existing VS
  Code, Sublime Text, micro, and Vim editor setup scripts.

## Compiler And Documentation

- `campc --version` now reports the stamped release version in packaged builds.
- Clarified interface constructor and destructor behavior in the language guide.
- Clarified that Linux x86 is supported as a generated-code target, but not as a
  host-tool distribution.

## Compatibility Notes

- Existing Camp projects are not expected to need source changes for this
  release.
- Linux x86 remains supported as a generated-code target. Camp does not provide
  a Linux x86 host-tool distribution.
