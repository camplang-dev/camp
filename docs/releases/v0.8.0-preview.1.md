Camp v0.8.0-preview.1 adds return-position `prep` declarations, new
environment/path/filesystem standard-library APIs, improved character-code
support, and fixes project-reference rebuild behavior.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Compatibility Notes

Standard-library prep methods now prefer return-position `prep` source spelling:

```camp
prep char[] getCurrentDirectory()
```

API headers and metadata still serialize prep methods in lowered form, with the
length return and explicit `prep` buffer parameter. Existing lowered prep
declarations remain valid source.

`FileOptions` is now an enum-flags-style value rather than a struct. Flags can
be combined with ordinary bitwise operators:

```camp
auto options = FileOptions.Read | Write;
```

The standard-library numerics source file is now named `std_numerics.camp`
instead of `std_math.camp`.

## Language

- Added return-position `prep` syntax for functions, methods, callables, and
  callable newtypes.
- Added body diagnostics for return-position prep methods, including warnings
  when the generated `buffer` parameter is not written or passed onward.
- Added Unicode scalar character literal handling. ASCII literals infer `char`,
  non-ASCII BMP literals infer `wchar`, and supplementary-plane literals infer
  `uchar`.
- Added target-typed enum bitwise operators for enum values.

## Standard Library

- Added environment, path, and filesystem APIs.
- Added path lexical helpers and runtime filesystem coverage across supported
  platforms.
- Changed `FileOptions` to an enum-flags-style API.
- Added `MIN`, `MAX`, `min`, `max`, `toString`, `hashcode`, `hashEquals`, and
  `HASH_POLICY` support for `achar`, `char`, `wchar`, and `uchar`.
- Updated standard-library prep APIs to use return-position prep source
  spelling.
- Renamed the standard numerics source file to `std_numerics.camp`.
- Updated standard-library categories for arrays and numerics.

## API Documentation And Metadata

- Generated API documentation now includes doc comments on members of static
  classes.
- API and metadata output preserve lowered prep signatures while tooling can
  display return-position prep where appropriate.

## Fixes

- Fixed project-reference cache invalidation so changed referenced project
  sources rebuild correctly.
- Fixed C emission for Unicode character literals, including supplementary
  Unicode scalar values.
- Fixed prep behavior in static-class and prepared-argument contexts.
- Fixed return-position prep diagnostics and generated buffer handling.
- Guarded unsupported environment mutation APIs on wasm/WASI targets.

## Documentation And Tooling

- Updated the language guide and semantic supplements for return-position prep,
  Unicode character literals, character primitive helpers, and filesystem APIs.
- Updated LSP/signature behavior for canonical prep signatures.
