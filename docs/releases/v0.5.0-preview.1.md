Camp v0.5.0-preview.1 adds caller-prepared results with `prep`, updates text
formatting around that model, and removes the old formatter API surface from
ordinary standard-library formatting.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Compatibility Notes

Formatting methods should now use caller-prepared buffers:

```camp
nuint format(in MyValue this, prep char[] buffer = default)
```

Callers can request scoped storage with `prep` or heap storage with `prep new`:

```camp
char[] scopedText = prep value.format();
char[] heapText = within (default) prep new value.format();
```

The old character formatter API surface has been removed from console, writer,
standard formatting, and interpolation paths. Code that used formatter delegate
values should move to `prep` methods.

## Caller-Prepared Results

- Added `prep` parameters for functions that write an array result into a
  caller-provided buffer.
- Added `prep` and `prep new` prefix calls, which perform the normal
  size-and-write sequence for prepared results.
- Added prep-aware property getter calls, so a getter with a prepared result can
  be used naturally with property syntax.
- Preserved `prep` in API metadata and callable surfaces.

## String Formatting

- Interpolated string holes now use prep-compatible formatting methods.
- Primitive, text, and time formatting APIs now use `prep char[]`.
- Console and character-writer numeric formatting now goes through prep-based
  formatting.
- Removed legacy formatter lowering from interpolated strings.

## Fixes

- Fixed prep formatter calls inside interpolated string holes.
- Fixed prep property getter interpolation holes.
- Added a clear diagnostic for unnecessary bare `prep` inside interpolation
  holes.
- Fixed source filename emission for numeric-looking filenames.
- Improved dev build `campc --version` output so it reports the nearest release
  tag plus the current commit hash.

## Documentation

- Updated the language guide, semantics guide, and LLM coding guide for
  caller-prepared buffers and prep-based formatting.
- Added standard-library documentation comments for assertion helpers and time
  APIs.
