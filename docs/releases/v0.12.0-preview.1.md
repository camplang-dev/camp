Camp v0.12.0-preview.1 adds factory tests: data-driven Camp tests that report each case independently while retaining the familiar `@test` entry point.

Camp remains early preview software. This release also includes a broad set of compiler-correctness, test-runner, incremental-build, and performance improvements.

## Factory Tests

- Added `@factorytest` for reusable, data-driven test bodies invoked from an ordinary `@test`.
- Added `@testname` to give each factory-test invocation a stable, useful reported name.
- Test output and JSON results now show factory-test cases beneath their parent test, including pass, failure, skip, and duplicate-name ordinals.
- Added nested test filtering such as `--filter parentTest/childCase`.
- Factory tests work through direct calls, function pointers, delegates, and lambdas in test-module code.

## Compiler And Build Improvements

- Improved incremental build and repeated Camp test execution.
- Expanded `--timing` output to show project-reference work and detailed C-emission phases.
- Reduced compiler work in declaration expansion and C emission, improving builds of larger projects.
- Coverage reporting now finds and reports generated project coverage maps.

## Fixes

- Fixed a broad set of lowering and generated-API issues involving arrays, conditional expressions, deterministic cleanup, iterators, lifecycle methods, namespace lookup, and project references.
- Fixed configuration-sensitive build freshness and test-harness behavior.
- Fixed Windows test and coverage harness hangs.
- Fixed raw-string newline handling across host platforms.
- Improved diagnostics around `within`, generated API declarations, callable parameter names, and test-only behavior.

## Tooling And Editor Support

- Updated syntax highlighting and language-service support for factory-test attributes.
- Improved factory-test discovery, filtering, result reporting, and coverage exclusion behavior.

## Compatibility Notes

- Factory tests are opt-in through `@factorytest`; existing `@test` functions continue to run normally.
