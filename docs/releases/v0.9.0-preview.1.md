Camp v0.9.0-preview.1 adds explicit `stackalloc` syntax and completes the
language cleanup that separates construction from storage allocation.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Compatibility Notes

`init` is no longer a Camp language keyword. Use the storage form that matches
the operation:

```camp
int[] heap = new int[count];
int[] scratch = stackalloc int[count];
fixed int[32] local = [];
```

Constructor-shaped calls now construct into storage already selected by the
destination. They do not allocate:

```camp
Widget value = Widget(args);
slot = Widget(args);
```

Use `new` when the object itself should live in allocator-backed storage, and
use `stackalloc` when it should live only for the current activation:

```camp
Widget* heap = new Widget(args);
Widget* scratch = stackalloc Widget(args);
```

`stackalloc` storage must not escape the current function activation and cannot
cross `await` or `yield` suspension.

## Language

- Added `stackalloc` for explicit dynamic activation-stack allocation.
- Added `stackalloc Type(args)` for stack-allocated constructor calls.
- Removed `init` as a language keyword/source form.
- Changed constructor-shaped calls to construct into already-selected storage
  instead of selecting storage themselves.
- Added explicit `stackalloc T` locals for erased/runtime-sized generic values.
- Required erased generic foreach variables to use explicit
  `foreach (stackalloc T item in ...)`.
- Treated `stackalloc` values as unavailable after suspension until source
  assigns them again.

## Fixes

- Added diagnostics for removed `init` forms and invalid stackalloc storage
  choices.
- Added lifetime diagnostics for stackalloc-backed values that escape, return,
  or cross suspension.
- Fixed iterator/generic stackalloc lowering so hidden runtime storage remains
  safe without restoring source values after `yield`.
- Improved the erased generic foreach diagnostic.

## Documentation

- Updated the language guide for `stackalloc`, constructor-shaped calls,
  allocation choices, generic storage, foreach, and iterator suspension.
- Updated semantic documentation for erased generic storage and stackalloc
  definite-assignment behavior after suspension.
