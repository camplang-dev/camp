Camp v0.9.4-preview.1 is a correctness release focused on compiler lowering fixes that affect inline declarations, scoped values, aggregate initialization, cleanup, conditional `params`, and prep method calls.

Camp is still early preview software. Package-management commands remain experimental and are intended mainly for Camp compiler development at this stage.

## Fixes

- Fixed inline `out` declarations, including uses inside lambda bodies.
- Fixed inline `out const char[]` declarations.
- Fixed empty array literal emission in generated C.
- Fixed inline aggregate array field initializers.
- Fixed cleanup for `finally` locals when loop control flow exits early.
- Fixed scoped local aggregate field assignments so scoped parameters can be copied into stack-local aggregate fields without being treated as escaping.
- Fixed conditional `params` argument expansion.
- Fixed prep receiver materialization for expanded values and instance expanded-return receivers.

## Documentation

- Updated Camp LLM coding guidance for current lifetime, visibility, and initialization patterns.

## Compatibility Notes

- Some previously failing valid programs involving inline `out`, scoped aggregate fields, conditional `params`, or prep receiver materialization now compile and emit valid C.
