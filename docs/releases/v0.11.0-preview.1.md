Camp v0.11.0-preview.1 introduces configuration requirements and the first source-only package publishing workflow.

Camp is still early preview software. Package-management commands remain experimental, but this release makes package restore and package caches much closer to the intended public model.

## Language And Configuration

- Added configuration flags, `requires (...)` declarations, and `configured(...)` checks for availability-sensitive source.
- Added flow-aware availability analysis so guarded code can call declarations that require the guarded configuration.
- Added conditional aliases and conditional `@symbol(...)` values for platform-specific bindings.
- Added target-declared configuration flags, callspec requirements, and typespec requirements.
- Replaced source conditional usage with configuration requirements in the standard library and documentation.

## Package Tooling

- Added source-only package catalogs and deterministic package archives.
- Added package restore from `versions.ini` catalogs into `cache/pkg`.
- Added `campc package` commands for package source management, install, uninstall, and publish workflows.
- Added `campc restore --only-local` to ignore compiler-root package sources.
- Added compiler-root `base.campbuild` and `global.campbuild` package source configuration.
- Added optional response-file includes with `@?file` for local build configuration.
- Added implicit single-`.campbuild` project target selection for build-like, restore, and package commands.

## Standard Library

- Moved atomic helpers into `std_atomic.camp`.
- Cleaned up standard-library availability requirements for filesystem, path, timing, and related platform APIs.
- Added POSIX atomic PAL support through compiler intrinsics.

## Tooling And Editor Support

- Updated syntax highlighting and editor grammars for `requires` declarations and related syntax.
- Improved language-service package lookup so it uses installed package cache behavior.
- Improved DAP source path handling.

## Fixes

- Fixed API emission for source-authored `destroy()` methods.
- Fixed override lookup for same-namespace signatures.
- Fixed configuration flag diagnostics when ordinary symbols named `TRUE` or `FALSE` are in scope.
- Fixed configured-branch analysis for return exhaustiveness and ternary expressions.
- Fixed several generic lowering and iterator lifted-local issues.

## Compatibility Notes

- `campc pkg` has been replaced by `campc package`.
- `lib/global.camp` has been replaced by compiler-root `base.campbuild` and ignored `global.campbuild`.
- Projects using old source conditionals or old package command names should update to the new configuration requirements and package command surface.
