Camp v0.2.0-preview.1 adds interpolated strings and formatter composition,
rounds out the formatter naming model, and fixes several rough edges found
while exercising the new text pipeline.

Camp is still early preview software. The package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## New Features

### Interpolated Strings

Camp now supports interpolated string syntax:

```camp
Console.writeLine($"Hello, {name}");
Console.writeLine($"Completed {done} of {total}");
```

Constant interpolated strings stay ordinary strings. Interpolated strings that
include runtime values lower to formatter delegates instead of implicitly
allocating primitive strings.

### Formatter Composition

Runtime text can now be composed through the formatter protocol, including with
textual `+`:

```camp
Console.writeLine("total: " + total);
```

Formatted runtime text remains allocation-conscious. When an allocated string is
needed, materialize it explicitly with the standard library formatter helpers.

### `StringFormatter`

The standard UTF-8 formatter type is now named `StringFormatter`. This replaces
the earlier `CharFormatter` name and better matches how the type is used by the
standard library, console output, and interpolated strings.

Custom formatter methods can participate in interpolation and text composition
by returning `StringFormatter`.

## Fixes

- Fixed generated C for formatter methods that access fields through an `in`
  struct receiver, such as `this.amount.format(buffer)`.
- Instance field initializers are now rejected with a diagnostic instead of
  being accepted as unsupported syntax.
- Installer scripts can resolve GitHub prerelease builds when installing the
  latest available Camp preview.

## Documentation And Tooling

- Expanded the language guide with interpolated string examples, formatter
  materialization, and custom `StringFormatter` usage.
- Expanded compiler semantics and LLM coding guidance for string interpolation
  and formatter composition.
- Updated syntax highlighting for interpolated strings in the bundled editor
  support files.
- Clarified that package management is experimental/development-preview
  infrastructure, not a stable public package ecosystem yet.

## Compatibility Notes

- Code using `CharFormatter` should rename it to `StringFormatter`.
- Instance field initializers are not supported. Initialize fields in
  constructors or through explicit assignment.
- Linux x86 remains supported as a generated-code target, but this preview does
  not include a Linux x86 host-tool distribution.
