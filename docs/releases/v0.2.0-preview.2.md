Camp v0.2.0-preview.2 adds starter project scaffolding and packages editor
setup scripts with release distributions.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## New Features

### Project Starters

`campc init` now creates small starter projects:

```sh
campc init hello
cd hello
campc run hello.campbuild
```

Use `--template` to start an executable, static library, shared library, native
API wrapper, or portable wrapper project. The generated projects use ordinary
`.campbuild` files, so there is no separate project format to learn.

### Editor Setup Scripts

Release archives now include optional editor setup scripts under
`extras/editors`:

```text
extras/editors/vscode/install.sh
extras/editors/sublime/install.sh
extras/editors/micro/install.sh
extras/editors/vim/install.sh
```

Windows archives include matching PowerShell scripts. VS Code installs the
bundled extension with syntax highlighting, language-server support, and
debugging. Sublime Text, micro, and Vim install syntax highlighting and configure
language-server support when the editor has a supported setup.

## Documentation And Tooling

- Added compiler-guide documentation for `campc init`.
- Added release-package smoke coverage for editor installer assets.
- Updated the Camp testing examples to use unnamed `thrown Assertion*` slots
  unless the test needs to reference the thrown slot directly.

## Compatibility Notes

- Existing projects are not affected by `campc init`; it only creates new
  project directories and refuses to overwrite existing files or directories.
- Linux x86 remains supported as a generated-code target, but this preview does
  not include a Linux x86 host-tool distribution.
