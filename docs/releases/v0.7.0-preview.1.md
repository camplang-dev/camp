Camp v0.7.0-preview.1 adds strict static classes, namespace-prefixed default
native symbols, namespace blocks, and multi-namespace API header support.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Compatibility Notes

Static classes now have strict static-class semantics. They are containers for
static members only; they cannot be instantiated or used as ordinary classes.
Members inside a static class must be declared `static`.

```camp
static class Metrics
{
	static int count;

	static void reset()
	{
		Metrics.count = 0;
	}
}
```

Namespaced declarations now receive namespace-derived default native symbols.
This makes source namespaces visible in the generated ABI and prevents ordinary
same-name declarations in different namespaces from colliding by default. Code
that depends on exact native names should use `@symbol` when it needs a stable
external spelling.

Standard-library declarations that previously lived in `Std::Math` or
`Std::Time` now live directly in `Std`.

## Static Classes

- Added strict `static class` behavior for static member containers.
- Enforced that static-class members are declared `static`.
- Prevented static classes from being treated as constructible ordinary types.
- Migrated `Console` to a static class.

## Namespaces And Native Symbols

- Added namespace-prefixed default native symbols for namespaced declarations.
- Added namespace blocks, which can place part of a file in another namespace.
- Added `namespace global` for root-namespace declarations inside files that
  otherwise use a namespace.
- Added `global::` qualification for explicitly naming the root namespace.
- Improved same-file qualified namespace lookup.
- Preserved source-level names for ordinary Camp lookup even when native
  symbols receive namespace prefixes.

## API Headers And Metadata

- Generated Camp API headers can now contain multiple namespace blocks.
- API headers now qualify references that cross namespace boundaries while
  keeping declarations readable inside their own namespace.
- Metadata tooling preserves namespace blocks for multi-namespace surfaces.

## Standard Library

- Updated the standard library for namespace-prefixed default symbols.
- Moved `Std::Math` and `Std::Time` declarations into `Std`.
- Kept raw external declarations in the global namespace where unprefixed native
  symbols are required.

## Fixes

- Fixed prep calls through interface dispatch so prep-bearing interface methods
  can be called with omitted buffers.
- Fixed static member calls in prepared arguments.
- Fixed `finally delete` with expanded returns.
- Fixed namespace-aware generic receivers and generic type aliases.
- Fixed generated shadow data type binding.
- Restored diagnostics for imported hidden symbols.
