Camp v0.9.1-preview.1 updates the shipped editor integrations for the
`stackalloc` language release.

Camp is still early preview software. Package-management commands remain
experimental and are intended mainly for Camp compiler development at this
stage.

## Editor Support

- Updated VS Code, Sublime Text, Fresh, Micro, and Vim syntax highlighting for
  `stackalloc`.
- Removed highlighting/completion support for the removed `init` keyword.
- Expanded Vim syntax coverage for current Camp keywords and primitive types.
- Updated fallback keyword completion in `camp-lsp` so it suggests
  `stackalloc` instead of `init`.

## Packaging

- Release packaging now rebuilds the VS Code extension from source instead of
  preferring a checked-in VSIX. This prevents stale syntax assets from being
  silently included in future Camp archives.
