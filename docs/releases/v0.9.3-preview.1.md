Camp v0.9.3-preview.1 is a small correctness release focused on compiler diagnostics, generated C correctness, target-spec parsing, and string literal encoding.

Camp is still early preview software. Package-management commands remain experimental and are intended mainly for Camp compiler development at this stage.

## Fixes

- Fixed UTF-8 encoded string literal lengths, including multi-byte characters in string and array contexts.
- Fixed C emission for escaped string receivers.
- Fixed virtual methods declared with `escaped this` receivers so virtual table slots, dispatch, and implementation thunks use a consistent receiver shape.
- Fixed virtual dispatch coverage for methods with array parameters so hidden array components are forwarded correctly.
- Fixed `catch _` with enum thrown slots so discard storage is typed correctly.
- Fixed target-spec parsing so valid target specs come from the selected target file instead of being inferred from leading underscores.
- Fixed project-reference artifact fallback behavior.

## Diagnostics

- Added diagnostics for non-constant static initializers.
- Added diagnostics rejecting `in` parameters whose declared type is non-copyable.

## Compatibility Notes

- `in` parameters now reject non-copyable declared types earlier and more clearly.
- Non-constant static initializers now produce compiler diagnostics instead of reaching invalid generated C.
- Leading underscore no longer implies a target spec; target specs are determined by the selected target file.
