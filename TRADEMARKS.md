# Camp Trademarks and Brand Use

The Camp source code is licensed under the MIT License. The MIT License covers the code and documentation in this repository; it does not grant permission to use Camp project identity assets in a way that suggests official status, endorsement, or affiliation.

Project identity assets include:

- the names `Camp`, `Camp Language`, and `campc`;
- the Camp logo and related artwork;
- the `camplang.org` domain and related website branding;
- official release names, package names, and distribution branding.

You may use these names truthfully to describe compatibility, origin, or history. For example, it is acceptable to say that a project is "forked from Camp", "compatible with Camp", or "built with Camp".

You may not present an unofficial fork, modified compiler, package, website, installer, or binary distribution as an official Camp project or release. Modified distributions should use distinct branding and should clearly identify themselves as unofficial.

Official Camp releases are distributed by the Camp project through project-controlled repositories, domains, and package-manager accounts.
